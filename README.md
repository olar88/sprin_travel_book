# spring_travel_book

簡短說明
---
`spring_travel_book` 是一個單頁式靜態範例網站，內容為「日月潭與九族賞櫻」的旅遊提案（HTML/CSS，使用 Tailwind）。此專案為作品展示與靜態範例，方便本地瀏覽與二次設計。

預覽與檔案
---
- 開啟本地檔案：請直接以瀏覽器開啟 [index.html](index.html)。
- 專案結構：
	- [index.html](index.html) — 單一頁面網站原始檔。

主要技術
---
- HTML5
- Tailwind CSS（透過 CDN）

在地執行（快速）
---
1. 直接在檔案總管用瀏覽器開啟 `index.html`。
2. 或在專案目錄啟動簡易靜態伺服器（例如 Python）：

```bash
# Python 3
python3 -m http.server 8000
# 然後於瀏覽器開啟 http://localhost:8000
```
